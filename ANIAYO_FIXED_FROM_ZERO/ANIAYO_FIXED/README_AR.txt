ANIAYO — النسخة الأولية
========================

ما الموجود؟
- واجهة عربية RTL بتصميم داكن.
- صفحة رئيسية وبطاقة ون بيس.
- نافذة تفاصيل وحلقات تجريبية.
- أزرار تبديل بين الترجمة والدبلجة (واجهة فقط حالياً).
- بحث ومفضلة/إعدادات تجريبية.
- غلاف Android بسيط مبني على WebView.

مهم:
هذه حزمة مشروع مصدر وليست APK جاهزاً. بيئة الإنشاء المستخدمة هنا لا تحتوي على Android SDK أو Gradle،
لذلك لم يتم تجميع APK. يمكن فتح مجلد المشروع في Android Studio ثم بناء APK.
لا توجد حلقات أو روابط بث داخل الحزمة. يجب ربط فيديوهات تملك حقوق عرضها، كما أن اختيار
الترجمة/الدبلجة لن يصبح فعلياً إلا بعد توفير ملفات الفيديو والمسارات الصوتية والترجمات المرخصة.

طريقة البناء:
1) افتح مجلد ANIAYO في Android Studio.
2) اسمح بمزامنة Gradle وتنزيل مكونات Android المطلوبة.
3) من Build اختر Build Bundle(s) / APK(s) ثم Build APK(s).
4) سيظهر ملف APK داخل app/build/outputs/apk/debug/.

متطلبات البناء: Android Studio حديث، JDK 17 أو أحدث، Android SDK 35.

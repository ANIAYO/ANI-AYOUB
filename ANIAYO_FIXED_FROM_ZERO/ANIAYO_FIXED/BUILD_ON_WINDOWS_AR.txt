طريقة بناء ANIAYO.apk من Windows باستعمال البناء السحابي
==========================================================

مهم جداً:
إذا كان جهازك ما زال Windows 7 بنظام 32-bit ومعالج Pentium 4 وذاكرة 4GB،
فإن Android Studio الحديث لا يناسبه. لا تضيع وقتك في محاولة تثبيته عليه.
يمكن استعمال Windows لرفع المشروع عبر المتصفح، بينما تتم عملية التجميع
على خوادم GitHub Actions.

الخطوات:
1) أنشئ حساباً في GitHub إذا لم يكن لديك حساب.
2) أنشئ مستودعاً جديداً باسم ANIAYO.
3) فك ضغط ANIAYO_windows_build.zip على جهاز Windows.
4) ارفع ملفات المشروع إلى المستودع مع الحفاظ على بنية المجلدات.
5) تأكد من وجود الملف: .github/workflows/android.yml
6) افتح تبويب Actions في المستودع.
7) اختر Build ANIAYO APK ثم Run workflow.
8) انتظر انتهاء المهمة بنجاح.
9) افتح نتيجة المهمة ونزّل Artifact باسم ANIAYO-APK.
10) فك ضغط الـ Artifact لتحصل على ANIAYO.apk.

ملاحظات:
- يتطلب حساب GitHub واتصال إنترنت.
- الناتج APK تجريبي Debug، وليس إصداراً منشوراً على المتجر.
- التطبيق الحالي واجهة أولية؛ لا يحتوي حلقات ون بيس ولا بثاً فعلياً.
  أزرار الترجمة والدبلجة حالياً تبدّل اختيار الواجهة فقط، وتحتاج لاحقاً
  إلى فيديوهات ومسارات صوت وترجمات مرخصة حتى تعمل المشاهدة.
